# 调度趋势设计

## 目标

首页调度情况默认展示网关趋势，点击网关趋势线后切换下方路由趋势；图表基于真实日志聚合，支持 TTFT、调度质量和吞吐量，窗口通过 ECharts dataZoom 调整。

## 数据口径

- TTFT：按桶内 `first_token_ms` 计算 `P95/P90/P50/AVG/Max`。
- 最终错误率：独立 `request_id` 最终一次尝试失败数 / 独立请求数。
- 顺延触发率：发生 `retry` 或 `failover` 尝试的独立请求数 / 独立请求数。
- 顺延恢复率：发生顺延且最终成功的独立请求数 / 发生顺延的独立请求数。
- 吞吐量：桶内独立请求数和每分钟请求数。

## 交互

- 上图绘制所有网关，每条曲线使用完整网关名称图例。
- 点击曲线或图例高亮网关，并同步切换下图路由集合、滚动到路由图。
- 下图绘制当前网关下全部路由，点击路由高亮。
- dataZoom 只调整绝对时间窗口；系统依据窗口跨度自动选择聚合粒度并在右上角显示起止时间、粒度和桶数。
- 趋势接口每分钟刷新一次；已闭合桶不变，当前桶可更新。

## 实现边界

后端新增独立趋势接口，保留现有 `/gateway/dispatch/stats` 汇总接口不变。前端新增 ECharts 依赖和趋势面板。seed 脚本提供 24 小时、多网关、多路由、失败与顺延链 mock。
